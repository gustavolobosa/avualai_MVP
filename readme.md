para subir nueva informacion de predios, cada semestre, se deben subir los archivos a las carpetas correspondientes de predios, info_rol y construcciones, luego correr el codigo preproces_propiedades.py con la linea: insertar_avaluo_periodo(chunk) comentada y la linea: insertar_predios(chunk) descomentada, luego de haber insertado todo, hacer lo mismo pero viseversa.

Luego se puede subir la infomracion de  info_rol con preproces_info_rol.py  que es solo para actualizar la superficie total de los roles no agricolas

finalmente se puede subir la infomracion de construcciones no agricolas con preproces_info_construcciones_no_agricolas.py y las agricolas con preproces_info_construcciones_agricolas.py
